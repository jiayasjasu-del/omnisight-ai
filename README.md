# omnisight-ai
OmniSight: Multimodal UI Self-Healing and RPA Agent


OmniSight AI is a Generative AI-powered software testing assistant designed to identify visual UI issues, suggest code corrections, and verify potential fixes through automated browser testing.

## Project Overview

Traditional UI testing often depends on fixed selectors and may not detect visual problems such as overlapping text, misaligned buttons, or responsive layout issues.

OmniSight aims to combine browser automation, multimodal AI, and automated workflows to make UI testing more intelligent and easier to maintain.

## Key Features

- Automated browser navigation and screenshot capture
- AI-powered visual UI issue detection
- Suggested CSS or React code corrections
- Screenshot-based verification of proposed fixes
- GitHub branch and pull request integration
- QA dashboard for reviewing detected issues and proposed fixes

*These features represent the planned project scope; implementation and testing are in progress.*

## Technology Stack

- **Backend:** Python, FastAPI
- **Browser Automation:** Playwright
- **AI:** Vision-Language Models (VLMs)
- **Version Control:** Git and GitHub
- **Frontend:** React

## Development Roadmap

1. Set up browser automation and screenshot capture.
2. Integrate AI-based visual issue detection.
3. Generate and verify proposed UI fixes.
4. Integrate GitHub pull requests.
5. Build the QA dashboard and evaluate results.
